## Core idea to build around
The packet is an immutable base layer. Everything a human does is an append-only event (verify, adjust, note, question, answer, sign-off, assign, freeze, amend), each pointing at refs from the packet. Current state = packet + replayed events. That one decision gives you: original never lost, who/why/when on everything, "since I last looked" (events after my last-seen cursor), version compare, undo (compensating event), freeze at filing (snapshot the event cursor), amend on top, and a self-contained notice-response export. Sign-offs store a hash of the nodes they cover; if any covered node's value or evidence changes, the sign-off shows reopened.

Organize the UI around the return line graph, not around forms: a line opens to its build-up (inputs, rule text, sources), each source opens the simulated document with the field highlighted, and each document shows everywhere it landed or a recorded reason it didn't.

## Stack (keep it boring)
